# Specimens

Build with `make build` and open `build/index.html`, or use `make preview`.
The page embeds WOFF2 and uses local assets without analytics or text uploads.
English and French copy describes dotmemo: free-form notes, tasks, calculations
and plain-text documents. Diagnostic character sets exercise specific glyphs.
The text files supply the initial preview, language buttons and outline proof.
Unsupported input is reported so fallback is distinguishable from font coverage.

`template.html` defines the interactive page. `texts/` holds specimen strings.
`current.svg` is an outline proof; update it deliberately after drawing changes.
